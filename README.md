# 初一学习 App

面向初一（七年级）学生的学习辅助应用。

## 目录结构

```
exams/       历年期末试卷（PDF 原件不入库，exams/txt/ 为提取文本，INDEX.md / index.json 为索引）
standards/   2022 版义务教育课程标准（PDF 原件不入库，standards/txt/ 为提取文本）
textbook/    七年级上册教材（PDF / 扫描图不入库，textbook/txt/ 为提取文本）
```

> 教材、试卷、课标的原始 PDF 与扫描图体积大且涉及版权，已通过 `.gitignore` 排除，仅保留本地副本。
