## 二、增补进设计的规则（各自的依据是本项目的研究）

1. **内容入库前先算每日负荷**。依据：报告 2.2 的 30 分钟模板里到期复习硬上限 10 分钟；已知量级——约 1100 条 FSRS 内容对应前 150 天中位约 14 分钟/天，再加 150 条就有四成天数超 20 分钟。规则：新内容文件 → `npm run sim` → 中位 ≤ 12 分钟、超 20 分钟天数 ≤ 10% 才装。
2. **每条内容带教材原句出处并逐字核对**。依据：总原则"有依据"；LLM 或人凭印象写的"原文"会错，错题的代价是把错的当对的练。
3. **默写卡两种形态**：默认 Anki 式接句卡（"海日生残夜，______"）——直接、无歧义、减少决策（研究 05）；情境卡（题面只描述功能情感场合、不露答案字）对应中考理解性默写题型（真题统计），在接句卡归档后出现——练习形式贴近考试形式（研究 02）。
4. **孩子只点"会 / 不会"，FSRS 四档由作答耗时推断**。依据：研究 05"减少决策"、研究 02"不采信自我感觉但采信表现"。
5. **听写卡的题面录音只对听写项发；音标/拼读/读音是答案级信息，答完才出现**。依据：研究 02 检索练习——任何提前出现的线索都在削弱检索。
6. **备份用 `vacuum into`，路径相对 `DATA_DIR` 存**。工程事实：WAL 模式直接拷 db 会拿到落后的快照；绝对路径换目录后图片全部 404。
7. **部署只走脚本**（停 → build → 起 → 探测）。工程事实：单独 build 会换掉运行中实例的产物。
8. **`node:sqlite`（Node 26 内置）**。依据：研究 04——孩子电脑零原生模块，运行时依赖只剩 `ts-fsrs`。

9. **引导式回想挂在章节勾选上，不做"白纸十分钟"**。来源：家长既有实现里的每日自由回忆（Wenderoth，《Make It Stick》第 8 章，课堂经验，C 级）。保留其三步机制（检索 → 对照 → 忘掉的喂回下一次），改形式的依据：Karpicke, Blunt & Smith 2016（小学生无引导自由回忆效果差，引导式检索有效）；Smith, Roediger & Karpicke 2013（默想与写出保持率相同）；研究 05 第 4 条（简短优于自由写作、点选式对中学生更可行）与界面规范"输入框只有单行"。对照物改为今天勾选的那一节的要点，而不是 app 里今天做过的卡。冷启动期（头两周无错题）这一步让第一天就有真正的检索。
