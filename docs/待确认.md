### 1. 章节树的叶子粒度与"要点"形式
- 生物/地理：叶子 = 节；历史：叶子 = 课；道法：叶子 = 框（课下的小节）。要点 3–5 条，都是教材原句。
- 语文：叶子 = 课文（含"课外古诗词诵读"里的每首诗、写作/专题活动）。**暂无要点**——语文一课的"回想"对照物应该是什么（生字词？主旨句？默写句？）我没把握，先只做勾选。
- 数学：叶子 = 节（1.1 … 6.3），要点直接用数学概念池的教材原句；2.2 / 3.2 / 5.3 池里没覆盖，暂无要点。
- 英语：叶子 = 单元的 Section A / B，**暂无要点**——英语的回想对照物更像是本单元词汇和句型，可以从词汇池按"单元"字段生成，但小学段词的"单元"是 Starter Unit 1–3 / Unit 1–3，本册新词的单元字段是空的（词汇池未标）。要不要花工夫给本册新词补单元？
- **你要决定**：语文、英语的回想要不要做，做的话对照物是什么。

### 2. 引导式回想的耗时基准与"会/不会"四档阈值
- 四档推断：不会 → Again；会且快于基准 0.6 倍 → Easy；≤ 1.5 倍 → Good；更慢 → Hard（`src/server/scheduler/rating.ts`）。基准 = 该条目最近 ≥3 次作答的中位耗时，不足时用种类基准表（`policy.ts`：默写 20s、概念 15s、答题模板 40s、文言注释 12s、单词 8s、听写 10s、错题 90s）。
- 这些数字都是假设，上线两周后用实测替换。**不用现在决定**，只是让你知道。

### 3. 情境卡解锁阈值
- 接句卡 FSRS 间隔 ≥ 30 天视为"成熟"，情境卡才出现。30 天是我定的，没有文献依据（研究 02 只说"接句卡归档后出现"）。可改 `policy.ts` 的 `ARCHIVE_INTERVAL_DAYS`。

### 4. 内容启用日（intro_day 的第 0 天）
- 暂定 **2026-09-07**（开学日），存在 `setting.content_start`。若想开学前一周先跑起来，改成 09-01 即可（首日到期量会因此多一点，模拟里第 1–30 天中位 6.9 分钟）。

### 5. "第 25 分钟插 3 分钟休息"的触发条件
- 硬约束 6 写的是"超过 30 分钟时在第 25 分钟插休息"，但第 25 分钟时还不知道会不会超 30。我的实现：**第 25 分钟时队列/步骤还没走完就休息 3 分钟**（`src/server/loop/timer.ts`）；能在 30 分钟内做完的不打断。
- **你要决定**：这个解释对不对；或者改成"到期卡超过 X 张才休息"。
